# Task 3 - ATM Interface

## Overview
A console-based Java application simulating a digital ATM machine. The system features user authentication and allows users to perform standard banking operations such as checking account balances, making deposits, withdrawing funds, and viewing transaction history.

## Key Features
* **User Authentication:** Secure login using User ID and PIN.
* **Transaction History:** Records and displays a history of all user transactions (deposits, withdrawals, and transfers).
* **Deposit Funds:** Allows users to deposit money into their account balance in real time.
* **Withdraw Funds:** Allows users to withdraw cash after checking for sufficient balance.
* **Transfer Funds:** Transfer money safely between different accounts.

## Tech Stack
* **Language:** Java (JDK 8 or higher)
* **Architecture:** Object-Oriented Programming (OOP) dividing logic across `ATM`, `Account`, `Bank`, and `Transaction` modules.
