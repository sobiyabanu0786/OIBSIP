# Task 2 - Number Guessing Game

## Overview
A console-based Java application where the system generates a random number within a specified range, and the player attempts to guess it within a limited number of tries.

## Key Features
* **Random Number Generation:** Uses `java.util.Random` to generate secret numbers.
* **Score & Attempt Counter:** Tracks the number of attempts and calculates scores based on performance.
* **Interactive Gameplay:** Provides instant feedback whether the guess is too high or too low.
* **Play Again Option:** Allows players to start new rounds easily.

## Tech Stack
* **Language:** Java (JDK 8 or higher)
* **API/Libraries:** `java.util.Scanner`, `java.util.Random`

## How to Run
1. Open terminal or command prompt.
2. Compile the Java file:
   ```bash
   javac NumberGuessingGame.java
